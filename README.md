# 試合タイムスケジュール（PWA）

Android / iPhone のホーム画面に追加して、アプリのように使えるタイムスケジュール管理ツールです。

## ファイル構成

```
match-schedule-pwa/
├── index.html          本体（このファイルを開く）
├── manifest.json        アプリ名・アイコン・色などの設定
├── service-worker.js     オフラインでも開けるようにするキャッシュ処理
├── icons/                アプリアイコン一式
└── README.md
```

## 重要：スマホにインストールするには「公開URL（https）」が必要です

PWAのインストール機能（ホーム画面への追加・オフライン動作）は、**httpsで配信されたURL**でないと正しく動作しません。パソコンのファイルをそのままAirDropやLINEで送ってスマホで開いても、通常のWebページとして表示されるだけで、インストールはできません。

以下のいずれかの方法で、まずこのフォルダをインターネット上に公開してください。どれも無料で数分で完了します。

### 方法A: Netlify Drop（一番簡単・アカウント登録不要）
1. https://app.netlify.com/drop を開く
2. このフォルダ（`match-schedule-pwa`）を丸ごとブラウザにドラッグ＆ドロップ
3. 発行されたURL（例: `https://xxxxx.netlify.app`）をスマホのブラウザで開く

### 方法B: GitHub Pages
1. GitHubに新しいリポジトリを作成し、このフォルダの中身をアップロード
2. リポジトリの Settings → Pages で公開を有効化
3. 発行されたURLをスマホで開く

### 方法C: Vercel / Cloudflare Pages
同様にフォルダをアップロードするだけで公開できます。

## インストール方法

### Androidの場合
1. 公開したURLをChromeで開く
2. 画面上部に「ホーム画面に追加して、アプリのように使えます」というバナーが出るのでタップ
   - 出ない場合はChromeの右上メニュー → 「アプリをインストール」

### iPhoneの場合
1. 公開したURLをSafariで開く（Chromeなど他のブラウザでは追加できません）
2. 画面下の「共有」ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択

インストール後は他のアプリと同じようにホーム画面のアイコンから起動でき、通信環境がなくても入力・閲覧ができます（LINE送信のみ通信が必要です）。

## データについて

入力内容は端末のブラウザ内（localStorage）に保存されます。他の端末とは自動的に同期されないため、複数人で共有する場合は「LINEで送信」または「コピー」でテキストを共有してください。
